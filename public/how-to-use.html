How to Use LabDrop

To share files from WhatsApp (or any other app) on your mobile, you don't need to catch your head searching for the file in the file explorer. You can simply click 'Share' on your phone, tap the LabDrop icon, and instantly transfer it! This is only possible if you install LabDrop. Check out the question below to learn how to download it.
To install LabDrop on your device, open this site in Chrome or Edge, tap the three-dot menu icon in the top right corner of your browser, and select 'Install LabDrop' or 'Add to Home screen'. It will install quickly and run like a native app!
