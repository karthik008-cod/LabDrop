Quick Answers to Common Questions

Can an expired transfer code be recovered?

No. Once the 30-minute timer for quick transfers expires, our automated cleanup script permanently hard-deletes the files and metadata from our servers. If you need 7-day retention, use the free "Save for Later" account feature.

Why was my file rejected with a "Dangerous File Type" error?

To protect student computers against malware distribution, LabDrop blocks dangerous executable scripts including .exe, .bat, .cmd, .msi, .vbs, and .ps1. Please bundle code into source text files (e.g. .c, .py, .java, .txt) or standard ZIP archives.

Does LabDrop charge any subscription or transfer fees?

No, LabDrop is completely free for all users. System hosting and cloud bandwidth are supported by non-intrusive advertisements served through Google AdSense.
