What's New in LabDrop

A continuous timeline of platform updates, new tools, and performance enhancements designed to keep college lab file transfers fast, private, and effortless.

November 3, 2026

What's New page & release timeline

  • Added a dedicated What's New timeline so students can see recent updates, new features, and improvements added to LabDrop.
  • Accessible directly from the homepage navbar, mobile menu, and global footer.
November 2, 2026

In-browser code, image and PDF viewers

  • In-Browser Code Viewer: View code files (.c, .cpp, .java, .py, .js, .html, .sql, .sh) right in your browser with line numbers and a 1-tap copy button.
  • High-Resolution Image Lightbox: Zoom and preview screenshots and photos before downloading.
  • Built-In PDF Viewer: Open lab manuals and assignment PDFs without needing a separate reader app.
  • Direct PowerPoint Downloads: PowerPoint files (.pptx, .ppt) download directly to open with full visual fidelity in Microsoft PowerPoint, Google Slides, Keynote, or WPS Office.
November 1, 2026

Add files to active transfers & multi-app staging

  • Append Files: Upload additional files directly to an ongoing transfer from the QR screen without generating a new code.
  • Real-Time Sync: Receivers automatically see newly added files appear on their screen with live download bars.
  • Draft Persistence: Stage files across separate apps (WhatsApp, Gallery, File Manager) onto your workbench without resetting previous selections.
October 20, 2026

Android share sheet support & sleek user menu

  • Android Share Sheet: Send files directly to LabDrop from the native Android share menu inside WhatsApp, Gallery, or Chrome.
  • Streamlined Account Menu: Consolidated 7-day saved transfers and session logout into a unified profile dropdown.
  • Laboratory Vector Icons: Replaced generic system emojis across desktop and mobile views with clean SVG vector icons.
October 15, 2026

LabDrop AI helper & transfer PIN protection

  • LabDrop AI Assistant: Interactive student companion for lab viva preparation, experiment summarization, and lab record assistance.
  • PIN-Protected Transfers: Optional 4-digit PIN verification to safeguard confidential lab assignments and academic submissions.
October 5, 2026

250MB file size limit & cloud speed upgrades

  • Capacity Expansion: Increased file allowance to 250MB per file, up to 30 files, and 1GB total transfer capacity per session.
  • Direct Cloud Uploads: High-speed multipart uploads engineered to sustain heavy campus laboratory network loads.
  • Homepage Quick Receive: Dedicated transfer code entry and camera QR scanner mounted directly on the primary workspace.
September 18 – October 4, 2026

Mobile ZIP downloads & full PWA install

  • Universal ZIP Archiving: 1-click Download All ZIP archives for multi-file transfers on iOS and Android.
  • Square QR Scanner: Centered mobile camera viewfinder with active laser scanning beam and target guide indicators.
  • Installable Progressive Web App: Direct home screen installation with laboratory styling, offline assets, and full-screen mobile support.
August 29 – September 11, 2026

Initial release & automatic 30-minute cleanup

  • Zero-Login QR File Drop: Rapid computer-to-phone file transfer in seconds without account registration or software installation.
  • 30-Minute File Cleanup: Server-side automated file destruction after 30 minutes, keeping shared university computer environments secure.
  • Save for Later Cloud Workspace: Seven-day optional cloud retention enabling registered students to store and retrieve assignments across devices.
